# Пакет LogicKernel

Здесь находятся 11 курсов по 60 уроков и 20 модулей, всего 660 уроков с практикой от первых шагов до продвинутых инженерных задач, публичные описания 6 отдельных задач и контракт API для будущего бэкенда

Каждый курс расширен в 5 раз по количеству уроков, цельные файлы находятся в `courses`, JSON предназначен для импорта, Markdown для чтения, готовые ответы 672 маршрутов находятся в `responses`

Уроки с 13 по 60 включают реализацию, проверку и проектные работы, используют стратегию `review`, три файла решения и критерии `exercise.review`, сервер принимает код и Markdown отчёт одним запросом, порядок подключения и проверки подробно описан в `BACKEND.md`

Подробное устройство проекта, объяснение файлов и полный порядок подключения сервера находятся в [технической инструкции](BACKEND.md), пути файлов приложения в ней указаны относительно корня полного проекта

`catalog-import.json`, все курсы и уроки одним документом для импорта

`courses/<courseId>.json`, один полный курс вместе со всеми уроками, `courses/<courseId>.md`, читаемая версия того же курса

`responses/courses/index.json`, готовый ответ каталога, `responses/courses/<courseId>.json`, программа курса, `responses/lessons/<lessonId>.json`, полный урок

`manifest.json`, версия, количества, список файлов и контрольные суммы ответов, `task-import.json`, публичный реестр отдельных задач с именами функций и версиями

`schemas`, форматы материалов, запросов и результатов для практик уроков и отдельных задач, `examples`, заполненные образцы запросов и ответов, `openapi.json`, машинное описание HTTP методов

`runtime-profiles.json`, требования к средам проверки, `fixtures/school-sqlite-v1.sql`, учебная база SQL, скрытые тесты и исполнители нужно реализовать на бэкенде

`serve.mjs`, пример API материалов без выполнения кода, `validate.mjs`, проверка пакета, `validation-report.json`, результат проверки

Курсы имеют идентификаторы `python`, `js`, `algorithms`, `html`, `sql`, `ts`, `csharp`, `c`, `cpp`, `go`, `rust`, отдельные задачи имеют идентификаторы `reverse`, `sum`, `palindrome`, `unique`, `fizzbuzz`, `binary`

В текущем локальном интерфейсе на отправку показывается сообщение «Проект ещё в разработке», в релизе фронтенд передаёт текст кода по HTTP, его выполнение, проверка и начисление наград находятся только на сервере

Для проверки самостоятельного пакета используй Node 24, команды выполняются из этой папки

```sh
node validate.mjs
node serve.mjs
```

Пример API доступен по адресу `http://127.0.0.1:4180/api/v1/courses`, он отдаёт материалы, на отправку решений возвращает ошибку об отсутствии серверной проверки
