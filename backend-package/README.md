# Материалы и учебные примеры API LogicKernel

**Свой Python-бэкенд команда пишет сама.** Здесь лежат данные курсов, образцы запросов и полный учебный пример для разбора. Начните с [BACKEND.md](BACKEND.md): он ведёт по функциям, показывает поток данных и порядок работы.

Для работы с интерфейсом возьмите полный проект `LogicKernel`. В ZIP только эта папка; файлов сайта в нём нет. Команды создания `public/` и запуска своего бэкенда в BACKEND.md выполняются из корня полного проекта, где находится `index.html`.

Команды в инструкции написаны для Linux. Сначала пишете свой бэкенд и запускаете локально, затем переносите готовые `public/`, `backend/` и эту папку на Linux VDS.

| Ваш следующий шаг | Где смотреть |
| --- | --- |
| Раздать страницы и начать Python-приложение | Шаги 1–2 BACKEND.md. |
| Создать БД и вернуть каталог и уроки | Шаги 3–4. Готовые ответы — в `responses/`. |
| Сделать регистрацию и вход | Шаги 5–7: сессия, cookie, CSRF, пользователи и пароли. |
| Сделать выход и сохранение профиля | Шаг 8. |
| Принять и сохранить решение | Шаги 9–11. |
| Вернуть попытку и историю её пользователя | Шаги 12–13. |
| Запустить своё приложение и пройти сценарии | Шаги 14–16. |

Полный код-ориентир: [examples/python_backend.py](examples/python_backend.py). Его запускаемый вид нужен, чтобы увидеть обмен и разобрать функции; свою реализацию вы пишете отдельно.

Папки для работы: `responses/` — готовые ответы материалов; `examples/` — сообщения и учебный Python-код; `schemas/` — точные требования к JSON; `courses/` — один курс целиком; `fixtures/` — учебные SQL-данные. Для импорта всей программы в свою БД берите `courses` и `lessons` из `catalog-import.json`, отдельные задачи — из `task-import.json`.

Сохраните эту папку рядом со своим Python-приложением, вне `public/`. Браузеру выдавайте данные через `/api/v1/`, как в инструкции.
