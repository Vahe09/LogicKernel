# Как писать бэкенд

Откройте [README.md](README.md). Весь Python-код там — учебный ориентир; команда пишет свою реализацию сама.

1. Шаги 1–4: файлы для браузера, основа приложения, SQLite и выдача курсов и уроков.
2. Шаги 5–8: сессия, регистрация, вход, выход и сохранение профиля.
3. Шаги 9–13: данные решения, сохранение попытки, GET по ID и история пользователя.
4. Шаги 14–16: запуск своего сервера, таблица всех адресов и проверка каждого этапа через интерфейс.

Функции разбираются в порядке реализации: входные данные → действия с БД → ответ браузеру → видимый результат. Полный учебный пример: [python_backend.py](backend-package/examples/python_backend.py).

Все команды в инструкции — для Linux. Готовый проект переносите на VDS после разработки.

После изменения README обновите копию и ZIP: `python3 tools/package-backend.py`.
