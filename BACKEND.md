# Подключение бэкенда LogicKernel

Полное устройство проекта и технический порядок подключения описаны в [главном README](README.md), копия этой инструкции для передачи вместе с материалами находится в [документации пакета](backend-package/BACKEND.md)

Все курсы и схемы собраны в [архиве для бэкенда](LogicKernel-backend-package.zip), каждый курс отдельно находится в папке `backend-package/courses`

Сейчас материалы доступны локально, при отправке решения интерфейс сообщает о разработке, пользовательский код в браузере не исполняется
